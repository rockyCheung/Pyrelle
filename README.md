# Pyrelle App 安装使用手册

> Pyrelle 是一个 AI 原生的桌面开发环境。它内置 Python 运行环境与 AI 助手，可以帮助你规划任务、编写代码、运行程序、排查问题，并支持多人云端协作。

## 1. 安装与启动

1. 从官网下载对应平台的安装包（macOS `.dmg` / Windows `.exe` / Linux `.AppImage`）。
2. 双击安装并打开 Pyrelle。
3. 首次启动会自动拉起内置的后端服务（终端窗口会显示初始化日志），等待状态栏出现「Ready」即可使用。

> macOS 首次打开若提示「无法验证开发者」，请在「系统设置 → 隐私与安全性」中点击「仍要打开」。

---

## 2. 注册与登录

1. 点击右上角头像（未登录时显示 👤）。
2. 选择「注册 / Login」，填写**邮箱 + 密码**完成注册。
3. 注册后自动登录；之后启动 App 会保持登录状态。

> 注册是免费的。未注册也可以作为游客使用部分本地功能，但**云端同步、协作邀请、官方模型**都需要登录。

## 3. 购买会员（Pro）

Pro 会员解锁：

- 使用**官方模型**（无需自备 API Key）。
- **可编辑（edit）协作**（与队友共同编辑同一项目代码）。
- 更高的云端存储配额与 AI Token 额度。

**购买步骤：**

1. 点击右上角头像 → 「升级 / Upgrade」。
2. 选择订阅周期（月度 / 年度），查看权益。
3. 点击「立即升级」，按提示扫码（微信/支付宝）或走 Stripe 完成支付。
4. 支付成功后，账号自动升级为 Pro，官方模型与编辑协作立即生效。

> 免费用户依然可以：使用自己的 API Key、使用 AI 助手（Auto/Dev/Chat）、单人云端同步。

## 4. 配置 API Key

如果你没有购买 Pro，也可以使用**自己的模型服务 Key**（如 DeepSeek / OpenAI）。

1. 点击右上角 AI 设置图标（⚙️ / Sparkles）。
2. 在设置里：
   - **Provider**：选择 `DeepSeek` 或 `OpenAI` 等。
   - **API Key**：粘贴你的服务商 Key。
   - **Model**：填写模型名（如 `deepseek-chat`）。
   - 其余参数（max tokens、temperature）可用默认值。
3. 保存后即可在 AI 助手中使用。

> **「使用官方模型」开关**：勾选后走 Pyrelle 官方中转（需要 Pro），无需自备 Key；不勾选则使用你自己的 Key。

## 5. 使用 AI 助手

右侧「AI 助手」面板支持三种模式，在顶部可切换：

| 模式 | 说明 | 适合场景 |
|------|------|---------|
| **Auto** | 全自动：AI 自主读项目 → 制定计划 → 分步执行（建任务、写文件、标记完成） | 直接下达需求，让它干活 |
| **Dev** | 项目感知：AI 了解项目结构，可读文件/搜代码辅助开发，产出文件需你确认后再保存 | 结对编程、局部修改 |
| **Chat** | 纯问答：不感知项目、不调用工具 | 概念咨询、代码问答 |

**快速上手（Auto 模式）：**

1. 打开一个项目（见下文「运行程序」）。
2. 在 AI 助手里输入，例如：`帮我写一个射击类的小游戏`。
3. AI 会先在**任务面板**里生成任务清单，然后自动逐项实现、保存文件、更新任务状态。
4. 你可以在左侧「任务」面板看到进度，在右侧文件树/编辑器看到产出。

**Dev 模式：** AI 产出的文件会先以「待确认」卡片出现，你点击「保存」才落盘。

## 6. 运行程序与解决问题

### 打开/创建项目

- 顶部项目名下拉 → 「打开文件夹」选择已有项目；或「新建项目」创建目录并初始化虚拟环境。

### 运行程序

1. 打开目标脚本（`.py` 等）。
2. 点击顶部「运行 ▶」按钮，底部「运行终端」会输出结果。
3. 也可以在底部「终端」手动执行命令（自动激活项目 `.venv`）。

### 发现与修复问题

- 点击顶部「编译检查」图标，会列出代码中的错误/告警。
- 每条错误旁边有「用 AI 修复」按钮，点击后 AI 会分析并给出/直接应用修复。
- 运行时报错时，AI 会识别异常堆栈，可一键让它定位并修复。

### 安装依赖

- 「包管理」页可以搜索并安装 Python 包；AI 也能在需要时自动帮你补依赖。

## 7. 云端同步与项目库

登录后，你可以把项目同步到云端（备份 + 跨设备 + 协作）。

- **推送（Push）**：顶部「同步」按钮，把本地改动上传到云端。
- **拉取（Pull）**：项目名下拉 → 「Pull from Cloud」，从云端恢复/拉取协作项目。
- **项目库**：查看「个人 / 协作 / 副本」三类项目；协作项目可拉取到本地共同编辑。
- **派生（Fork）**：把协作项目复制一份到个人空间。

## 8. 云端协作与发起邀请

### 发起邀请

1. 打开项目 → 顶部「协作/邀请」入口（Share 面板）。
2. 选择受邀人**邮箱**（多个用逗号分隔）。
3. 选择**权限**：

| 权限 | 说明 |
|------|------|
| 只看（view） | 只能查看项目产物 |
| 可评论（comment） | 查看 + 发表评论 |
| 可批准（approve） | 评论 + 批准/驳回决策 |
| 可编辑（edit） | 完整编辑权限（**需 Pro**，受邀人也可 Pull 项目共同编辑） |

4. 选择可见范围（整个项目 / 指定产物）、有效期。
5. 点击「发送邀请」。

### 受邀人如何收到

- **已注册用户**：App 顶部「铃铛」会收到邀请通知，在消息里即可查看/评论/批准；edit 邀请在消息里「接受」后即可在项目库拉取。
- **未注册用户**：会收到**邮件**，内含魔法链接，点开即可查看/评论/批准（无需注册）。edit 邀请需要先注册登录 App 后接受。

### 协作动态

发起人在 Share 面板可看到每位受邀人的处理结果：已查看、评论内容、同意/拒绝、接受/拒绝，以及可随时**撤销邀请**。

## 9. 常见问题 FAQ

**Q：官方模型和自带 Key 有什么区别？**
A：官方模型走 Pyrelle 中转、需 Pro、开箱即用；自带 Key 用你自己的服务商额度，免费即可用。

**Q：编辑协作为什么提示需要 Pro？**
A：edit 权限会消耗云端协作资源，仅对 Pro/Enterprise 开放。

**Q：同步按钮在哪？**
A：只有协作项目（有 edit 成员）在顶部显示「同步」按钮；个人项目在 Share 面板或项目库中同步。

**Q：AI 生成的文件没看到？**
A：确认当前在「代码」页，并点击左侧文件树顶部的「刷新」；或确认 Dev 模式下是否已点击「保存」。

**Q：登录后没收到邀请？**
A：确认邀请发到你当前登录的邮箱；未注册时邀请走邮件链接。
